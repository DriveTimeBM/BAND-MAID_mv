# BAND-MAID MV Locations

An interactive map of real-world filming locations from BAND-MAID's official music videos. Browse MVs, see exactly where each scene was shot, and jump directly to the moment in the video where that location appears.

[**Live site →**](https://drivetimebm.github.io/BAND-MAID_mv/)

Most of the location data in this project comes from a massive amount of detective work done by **Simeon from Brazil**, who built [this incredible Google Map of BAND-MAID MV locations](https://www.google.com/maps/d/u/0/viewer?mid=1-hUU-25MYERexy7XrFTF_vi1S9l550Q1&ll=-3.81666561775622e-14%2C0&z=1). ## Features

- **MV browser** with a list of every official BAND-MAID music video that has identified locations
- **Embedded YouTube player** that stays pinned to the top of the column while you scroll the place list
- **Clickable timestamp chips** in the place details — clicking `0:21–0:24` seeks the video to that moment
- **Interactive map** with numbered gold pins, popups, and fly-to behavior when you select a place
- **Map style picker** — choose between OpenStreetMap, Positron (light), Voyager (muted), and (with a free MapTiler key) MapTiler Streets/Basic
- **Map language picker** — when MapTiler is configured, switch labels between Local, English, Japanese, Spanish, French, German, Chinese, Korean, Russian, Arabic, Portuguese, or Italian
- **Auto-resolves location names** ("Shibuya, Japan") from coordinates via reverse geocoding
- **Per-place image galleries** with lightbox viewer
- **One-click Google Maps link** for every place
- **Preferences persist** across visits via `localStorage`
- **Responsive** — three-column desktop, stacked mobile

## `mv.json` schema

```jsonc
[
  {
    "Song": "Don't Let Me Down",
    "VideoId": "X8aJTXRdRGw",
    "Places": [
      {
        "Lat": 35.6586,
        "Lon": 139.7454,
        "Scene": "0:19-0:22, 0:41-0:49, 0:54-0:56",
        "Description": "Optional descriptive text about the location",
        "Images": "d5c8328ca1301f05.jpg",       // string OR
        "Images": ["a.jpg", "b.jpg"],            // array of strings, OR omit
        "Location": "Shibuya, Japan"             // populated by Update-MvLocations.ps1
      }
    ]
  }
]
```

**Field notes:**

- `Scene` — free-text. Any timestamps in `M:SS` or `H:MM:SS` format (alone or as `start-end` ranges) become clickable chips that seek the YouTube player. Non-timestamp text just displays as-is.
- `Images` — accepts a single string filename, an array of filenames, or `null`/missing. Filenames are resolved against the `images/` folder.
- `Location` — optional human-readable place name. Generated by the reverse-geocoder script; falls back to raw lat/lon if missing.
- `VideoId` — the YouTube video ID (the part after `?v=` in the URL).

## Reverse-geocoding script

`Update-MvLocations.ps1` adds the `Location` field to every place in `mv.json` using OpenStreetMap's free Nominatim service.

```powershell
.\Update-MvLocations.ps1
```

It's idempotent — places that already have a `Location` are skipped. Use `-Force` to re-geocode everything. The script also fixes any UTF-16 encoding on the JSON file (writes back as UTF-8 without BOM).

Nominatim's usage policy requires 1 request/second, so a full run of ~120 places takes a couple of minutes.

## Configuration

All paths and keys live near the top of the `<script>` block in `index.html`:

```javascript
const REPO_BASE   = 'https://drivetimebm.github.io/BAND-MAID_mv/';
const JSON_URL    = REPO_BASE + 'mv.json';
const IMAGE_BASE  = REPO_BASE + 'images/';
const MAPTILER_KEY = '';   // Optional — see below
```

### Enabling map languages (optional)

Standard OSM tiles have labels baked into the PNGs, so language is fixed by the cartographer (Tokyo shows in Japanese, Paris in French, etc.). To enable user-selectable label languages:

1. Sign up at [maptiler.com/cloud](https://www.maptiler.com/cloud/) — free tier is 100,000 tile loads/month, no credit card required
2. Copy your API key
3. Paste it into `MAPTILER_KEY` in `index.html`

The MapTiler styles and the **Lang** dropdown will appear automatically once a key is present.

## Running locally

It's a static site, but the YouTube IFrame API and `fetch()` for `mv.json` need to run from a real HTTP server (not `file://`):

```powershell
# Python 3
python -m http.server 8000

# or Node
npx serve
```

Then open `http://localhost:8000`.
